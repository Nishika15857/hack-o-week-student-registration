# Hack-O-Week: Student Registration System

A beginner-friendly web application created for 3rd semester CSE Hack-O-Week (Week 9 & 10).

## 📌 Project Objectives
1. **JavaScript Error Handling**: Demonstrating `try`, `catch`, `throw`, and custom `ValidationError` extending `Error`.
2. **NPM Basics**: Demonstrating `npm init`, `npm install`, `package.json`, `package-lock.json`, and `node_modules`.
3. **Git & GitHub Workflow**: Complete workflow with branches, commits, pull requests, and merging.

## 📁 Project Structure
```text
hack-o-week-student-registration/
│
├── index.html         # Frontend Form & UI Structure
├── style.css          # Clean & Modern Styling
├── script.js          # JavaScript Validation & Error Handling
├── package.json       # Node Package Configuration
├── .gitignore         # Ignores node_modules from Git
└── README.md          # Project Documentation
```

## 🚀 How to Run Locally
1. Simply double-click `index.html` or open it in any web browser.
2. (Optional) Run `npm install` in your terminal to see NPM dependency management in action.
